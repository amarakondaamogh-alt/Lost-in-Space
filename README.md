# Lost In Space

A 10-level 2D pixel-art platformer made in Unity. You're an astronaut lost in space: collect the crystals, step on the switch to unlock the door, and reach your rocket. Beat all 10 worlds to make it back to Earth.

## Worlds

| Level | World | Twist |
| --- | --- | --- |
| 1 | Lost in Space | The basics |
| 2 | Ice Planet | Slippery ground |
| 3 | Lava Planet | Lava floor |
| 4 | Ocean Planet | Floaty underwater jumps |
| 5 | Desert Planet | Blowing sand, twin suns |
| 6 | Crystal Caves | Glowing cave |
| 7 | Toxic Swamp | Toxic floor |
| 8 | Storm Planet | Rain and lightning |
| 9 | The Moon | Low gravity |
| 10 | Earth | Almost home! |

Watch out for spikes and moving hazards - touching one sends you back to the last checkpoint.

## Controls

| Action | Keys |
| --- | --- |
| Move | A / D or Left / Right arrows |
| Jump | Space (or W / Up arrow) |
| Back to checkpoint | R |
| Mute music | M |
| Pause | Esc |

Gamepads work too (left stick, A / bottom button, Start).

## Goal (every level)

1. Collect all the crystals.
2. Step on the switch to unlock the door.
3. Go through the door and reach the rocket.

## Opening the project

- Unity version: **6000.6.7f1** (Unity 6)
- Open the `Lost In Space` folder from Unity Hub.
- Start from the `MainMenu` scene to play the full game.
- **Lost in Space > Set Up Everything** re-wires the levels and menus if anything looks broken.
- **Lost in Space > Build for itch.io (Web)** makes a browser build in `Builds/WebGL`.

## Music

The game makes its own background tune. To use your own song, put an audio file at
`Assets/Audio/Music/Resources/SpaceCadet.mp3` (any song you have the rights to).
